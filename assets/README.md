# Sample assets

Small media files used by the demo project, tests and documentation.

- `images/ofTheo.jpg` — background layer in the demo project.
- `images/car.jpg` — foreground layer in the demo project, showing an ordered
  two-layer stack with the `Screen` blend mode.
- `video/fingers.mov` — demo H.264 clip used by the video decoder example and
  playback checks.

These files were copied from the archived LPMT 1 data set for continuity. See
[`archive/lpmt-1/`](../archive/lpmt-1/) for the originals and the repository
license for terms.
